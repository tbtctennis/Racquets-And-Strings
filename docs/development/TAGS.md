# Tags

A task or bug may carry more than one tag.

| Tag        | Use for                                                |
| ---------- | ------------------------------------------------------ |
| `QA`       | Verification, reviews, typecheck, lint                 |
| `API`      | Cloud Functions, callables, server payouts             |
| `Firebase` | Auth, Firestore, Storage, Hosting, emulators, projects |
| `UI`       | Screens, components, copy, layout                      |
| `Docs`     | Planning, workflow records, policies                   |
| `Auth`     | Identity, consent, connections, roles                  |
| `Rules`    | Firestore / Storage security rules                     |
| `Data`     | Shape, migrations, backfill, snapshots                 |
| `Payments` | Stripe, donations, refunds, badges                     |
| `E2E`      | Playwright / browser emulator journeys                 |
| `Planning` | Decisions, milestones, platform choices                |
| `Staging`  | Isolated staging project, seed, PWA install            |
